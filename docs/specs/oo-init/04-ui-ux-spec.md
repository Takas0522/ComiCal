# 04. UI / UX 仕様

## 4.1 画面一覧

| ID | 画面 | パス | 概要 |
|---|---|---|---|
| P-01 | ホーム | `/` | 直近発売予定 + 購読中のみトグル |
| P-02 | カレンダー | `/calendar` | 週・月カレンダービュー |
| P-03 | 検索 | `/search` | タイトル / 著者 / 発売日 From / 出版社 |
| P-04 | 購読一覧 | `/subscriptions` | 自分の購読シリーズ |
| P-05 | シリーズ詳細 | `/series/:id` | 全巻リスト + 購読・購入操作 |
| P-06 | 設定 | `/settings` | テーマ / アフィリエイト ON/OFF / アカウント削除 |
| P-07 | ログイン | `/login` | Microsoft / Google / X(Twitter) |
| P-08 | 法務 | `/legal/{privacy,terms,oss}` | 静的ページ |

## 4.2 グリッド / レスポンシブ

- カードグリッドの列数:
  - **モバイル (<640px): 2 列**
  - **タブレット (640–1024px): 4 列**
  - **デスクトップ (>1024px): 6 列以上**（コンテナ幅に応じて自動増加）
- 漫画情報は **カードグリッドで密度高く表示** することを最優先。
- カードのアスペクト比は表紙の標準比率（≈ 1:1.4）を維持。

## 4.3 カードコンポーネント

```
┌─────────────────┐
│  [表紙サムネ]    │  ← Blob 直接配信、loading="lazy"、AVIF/WebP
│                 │
├─────────────────┤
│ シリーズ名 + 巻 │
│ 著者            │
│ 2026年5月15日   │  ← ReleaseDateIsMonthOnly 時は「2026年5月」
│ [購読中] [購入✓]│
│ [楽天 Books ↗]  │  ← settings.affiliateLink === ON のみ
└─────────────────┘
```

- 購読状態バッジ: `購読中 / 未購読`。
- 購入チェックボタン: アイコンの状態遷移 (`未購入 → 予約中 → 購入済 → 読了` の 4 状態をプルダウンでも選択可)。
- 表紙サムネのキャッシュ戦略: HTTP `Cache-Control: public, max-age=2592000, immutable`（30 日）+ `CoverHash` ベースの URL（不変 URL）。

## 4.4 一覧 / ページネーション

- **無限スクロール（keyset pagination）** を採用。OFFSET ベースは禁止（深いページで遅延するため）。
- カーソルキー: `(ReleaseDate ASC, VolumeId ASC)`。
- ロードトリガー: ビューポート下端から 200px 手前で次ページを fetch。
- ページサイズ: モバイル 20 件 / デスクトップ 60 件。

## 4.5 ナビゲーション

- ヘッダー: ロゴ + グローバル「購読中のみ」トグル + 検索アイコン + アカウントメニュー。
- フッター: 「Powered by Rakuten Books」+ プライバシー / 利用規約 / OSS 情報リンク。
- モバイルはボトムナビ (`Home / Calendar / Search / Subscriptions / Settings`)。

## 4.6 状態フィードバック

| 状態 | 表現 |
|---|---|
| ローディング | スケルトンスクリーン（カード形状）。スピナーは使わない |
| 空状態 | 説明文 + サンプルシリーズの提示（オンボーディング兼用）|
| エラー | トースト + 「再試行」アクション |
| 成功 | トースト 3 秒。購読/解除は 5 秒以内に「元に戻す」可 |

## 4.7 ダイアログ

- **OSS 情報ダイアログ**（`/legal/oss` の内容を画面から開ける軽量ダイアログ版）。
- アカウント削除ダイアログ: タイトル名入力で削除確認（誤操作防止）。

## 4.8 アクセシビリティ（WCAG 2.1 AA 準拠）

| 観点 | ルール |
|---|---|
| キーボード | 全操作をキーボードのみで完結可能。Tab 順序は視覚順序と一致 |
| スクリーンリーダー | カードに `aria-label`、状態変更は `aria-live="polite"` |
| コントラスト | テキスト 4.5:1 以上、大文字 3:1 以上。Tailwind v4 の `@theme` トークンで管理 |
| フォーカス | 視認性の高いフォーカスリング（`outline: 2px solid var(--ring)`）|
| 動きの軽減 | `prefers-reduced-motion` でアニメーションを無効化 |
| `data-testid` | E2E テスト用に **すべての操作可能要素に付与必須**（コンポーネント実装規約）|

## 4.9 パフォーマンス（UX 視点）

- **LCP < 2.5s**（カードグリッドの表紙サムネ最初の 1 件をターゲット）
- **TTFB < 600ms**（SSR + Transfer State）
- **CLS < 0.1**（カードのアスペクト比固定で防止）
- 画像は `loading="lazy"` + `decoding="async"`。1 画面初期描画は 12 件まで eager。
