# 02. ターゲット / ロケール / MVP スコープ

## 2.1 ターゲットユーザー

- **日本国内の漫画読者（個人）** に限定。
- 週 1 冊以上漫画を購入する、または書店アプリ・電子書店アプリを跨いで購読シリーズを管理することに不便を感じているユーザー。
- 個人利用専用。法人 / 書店 / 出版社向け機能は持たない。

## 2.2 ロケール

- **日本語のみ提供**。
- ただし将来の多言語化に備え、`@angular/localize` でメッセージ抽出可能なリソース設計を採用する（実装は日本語キーのみ）。
- 日付フォーマット: `YYYY年M月D日` をユーザー表示。内部は ISO 8601。
- タイムゾーン: Asia/Tokyo (JST, UTC+9) を既定。

## 2.3 MVP スコープ

### In Scope

| 区分 | 機能 |
|---|---|
| 購読 | 購読シリーズの登録・解除・一覧表示 |
| カレンダー | 発売予定の **週 / 月カレンダービュー** |
| 一覧 | 直近の発売予定一覧（無限スクロール、発売日昇順）|
| 購入管理 | 巻ごとの購入状態管理（未購入 / 購入済 / 読了 / 予約中）|
| 検索 | タイトル / 著者 / 発売日 From / 出版社の部分一致 + ひらがな正規化 |
| 認証 | Entra External ID（Microsoft / Google / X）|
| 匿名 | デバイスローカル保存（IndexedDB）+ QR コードでの端末間同期 |
| 設定 | アフィリエイトリンク表示 ON/OFF、テーマ（ダークモード）|
| 法務ページ | プライバシーポリシー / 利用規約 / OSS 情報ダイアログ |

### Out of Scope (MVP では実装しない)

- 電子書籍ストア連携購入（リダイレクト以外）
- ソーシャル機能（フォロー、コメント、シェア OG カード）
- AI レコメンデーション / ディスカバリ
- スタンプラリー / ゲーミフィケーション
- Web Push / メール通知（将来拡張）
- PWA / オフライン書架
- 未読・既読管理（将来拡張）
- ウィッシュリスト（将来拡張）

## 2.4 リリース戦略

- **MVP リリース** 後、Feature Flag (Azure App Configuration) で段階的に機能を有効化する。
  - Entra External ID ログインの段階ロールアウト。
  - レコメンド / ディスカバリ機能のカナリア。
  - カレンダービュー A/B テスト。
- 環境は **dev / prod の 2 環境** のみ。staging は prod スロット運用で代替。
