# 21. 将来拡張候補（非 MVP）

`init.md §16` を継承。MVP 出荷後に Feature Flag を併用しつつ段階導入する候補機能を整理する。

## 21.1 通知 / リマインド

- **Web Push**（Service Worker + Push API）。
- **メール通知**（Azure Communication Services Email）。
- リマインドタイミングは **ユーザー設定可能**（例: 7 日前 / 前日 / 当日）。
- 必須実装:
  - 通知購読の opt-in と購読管理 API。
  - バッチ後にスケジュール投入（Storage Queue + Time-Trigger Function）。
  - 配信履歴と再送制御。

## 21.2 読書状態の拡張

- **未読・既読管理**（`Purchases.State` の拡張または別テーブル化）。
- **ウィッシュリスト**（購読より弱い「気になる」状態）。

## 21.3 検索強化

- **Azure AI Search** によるフルテキスト検索の高度化（シノニム / Fuzzy / 顔文字対応）。
- 「あなたへのおすすめ」ランキング。

## 21.4 ディスカバリ / レコメンド

- 購読履歴ベースの類似シリーズレコメンド。
- 出版社 / 著者・トレンドビュー。

## 21.5 共有 / 公開

- **OG カード自動生成**（シリーズ詳細 / 購読一覧）。
- **公開リンク**（ユーザーが希望した場合のみ、購読リストの限定公開）。

## 21.6 配信最適化

- **Azure Front Door (CDN)** 経由での配信。
- 表紙画像の **AVIF / WebP 変換**（Image Resizer Function）。

## 21.7 マルチプラットフォーム

- PWA 対応（インストール可・オフライン購読閲覧）。
- ネイティブアプリ（Capacitor / Tauri）。

## 21.8 i18n

- 英語 / 中国語簡体への対応（楽天 Books API は日本国内限定なのでデータ拡張は別 API）。

## 21.9 評価 / レビュー

- ユーザー個人の星 / メモ。SNS 連携や公開はしない。

## 21.10 段階導入ポリシー

- すべて **Feature Flag (Azure App Configuration)** で OFF 起動。
- 各機能は ADR + STRIDE（軽量）+ プライバシーレビューを通してから ON にする。
- 「広告」「SNS 共有のうち公開機能」「収益機能（直接課金）」は MVP の方針上 **慎重に検討**。
