# 01. ビジネス概要

## 1.1 プロジェクトミッション

ComiCal（UI 表示名: **まんがリマインダー**）は、**日本国内の漫画読者個人** が「読みたい」と登録した漫画シリーズの **発売予定を取りこぼさず把握** し、**購入・読了状態を一元管理** することを目的とした Web アプリケーションである。

楽天 Books API を漫画発売情報の唯一のソース・オブ・トゥルースとし、コミックジャンル (`booksGenreId = 001001`) のみを対象に、毎日定期収集して提供する。

## 1.2 提供価値（What）

| # | 価値 | 説明 |
|---|---|---|
| V1 | 発売情報の自動集約 | 楽天 Books API から **これから 6 ヶ月先まで** の漫画発売情報を毎日 03:00 JST に自動収集 |
| V2 | 購読管理 | ユーザーは興味のあるシリーズを購読登録し、直近の発売予定を即座に確認できる |
| V3 | 購入・読了管理 | 巻ごとに「未購入 / 購入済 / 読了 / 予約中」の状態を記録できる（電子・紙の区別なし）|
| V4 | クロスデバイス同期 | External Identity でログインすればデータをクラウドに保存し、デバイス間で同期できる |
| V5 | 匿名利用 | ログインしなくてもデバイスローカル（IndexedDB）で購読・購入を管理でき、QR コードで他端末に同期可能 |
| V6 | 高密度な視覚カタログ | 表紙サムネイルを中心としたカードグリッドで漫画情報を密度高く一覧できる |
| V7 | 柔軟な検索 | タイトル / 著者 / 発売日 From / 出版社で部分一致 + ひらがな正規化検索ができる |

## 1.3 表示要素（カード）

- 表紙サムネイル
- タイトル
- 巻数
- 著者
- 発売予定日（未定 / 月のみ も表現可能）
- 購読状態バッジ
- 購入チェックボタン
- 楽天 Books へのアフィリエイトリンク（ON/OFF 設定可）

## 1.4 ステークホルダー

| ロール | 関与 |
|---|---|
| エンドユーザー（個人読者）| 主要な利用者。匿名 / ログインの両方を選択可能 |
| Admin（運用者）| シリーズ集約の手動補正、バッチの手動再実行、シードデータ管理 |
| プロジェクト保守者（OSS コミッタ）| MIT ライセンス OSS としての保守 |
| 楽天（API 提供者）| 楽天 Books API の提供元。アフィリエイト規約への準拠が必須 |
| Microsoft Azure | ホスティング基盤。Azure SLA / コスト最小化原則に従う |

## 1.5 制約・前提

- **収益モデル**: 楽天アフィリエイト経由のみ（直接課金なし）。
- **可用性 SLA**: 無指定（ベストエフォート）。コスト最小化を優先。
- **DR**: 不要。リージョンは Japan East 単一。
- **市場 / 通貨**: 日本国内 / JPY。
- **OSS**: MIT ライセンスとして公開。
- **法務**: 「Powered by Rakuten Books」クレジットを必須表示。
