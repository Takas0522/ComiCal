# ComiCal Batch (Durable Functions)

Phase 1 batch worker that pulls manga release data from the Rakuten Books API
and UPSERTs Publishers / Authors / Series / Volumes / ThumbnailAssets.

## Functions

| Name | Type | Description |
|---|---|---|
| `DailyReleaseTrigger` | Timer | `0 0 18 * * *` (UTC = 03:00 JST). Schedules `DailyReleaseOrchestrator`. |
| `ManualBatchTrigger` | HTTP `POST /api/batch/runs` (function-key) | Schedules `DailyReleaseOrchestrator` on demand. |
| `DailyReleaseOrchestrator` | Orchestrator | StartBatchRun → fan-out FetchRakutenPage → fan-out UpsertSeriesAndVolume → fan-out EnsureCoverThumbnail → FinishBatchRun. On failure: FailBatchRun. |

## Determinism

The orchestrator is strictly deterministic: no `DateTime.Now`, no `Guid.NewGuid()`,
no `Random`, no I/O, no static mutable state. The `RunId` is generated by the trigger
and carried in `BatchRunInput`. Logging uses `context.CreateReplaySafeLogger`.

## Run locally

```bash
# In a separate terminal, start Azurite
azurite --silent --location ./.azurite

# Restore + build
dotnet build src/backend/batch/ComiCal.Batch.csproj

# Run the function host
cd src/backend/batch
func start

# Manual run (function key from `func` startup output)
curl -X POST http://localhost:7072/api/batch/runs \
  -H "x-functions-key: <key>" \
  -H "Content-Type: application/json" \
  -d '{"keyword":"コミック","dryRun":false}'
```

The response is the standard Durable Functions check-status payload with
`statusQueryGetUri`, `terminatePostUri`, etc.

## Configuration

| Setting | Source | Notes |
|---|---|---|
| `AzureWebJobsStorage` | Azurite (dev) / Storage account (prod) | Required for Durable Task hub state. |
| `SqlConnection` | Key Vault reference | Azure SQL connection string. |
| `RakutenBooks__ApplicationId` | Key Vault reference | Rakuten Books API App ID. |
| `BlobStorage__*` | Key Vault reference | Cover image container settings. |
